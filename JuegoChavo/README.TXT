PROJECT TITLE: La Vecindad del Chavo del 8 (MVC en Java/BlueJ)
PURPOSE OF PROJECT: Juego donde los personajes de la vecindad hablan, se mueven, interactuan entre ellos y con los objetos.
HOW TO START THIS PROJECT: Clic derecho sobre la clase Main -> void main(String[] args)
STRUCTURE: paquete modelo (Personaje, Chavo, Quico, DonRamon, Florinda, ObjetoInteractivo, Barril, Casa, Vecindad), paquete vista (JFVecindad), paquete controlador (Control), Main.
